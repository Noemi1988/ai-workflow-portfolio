# Word Search Puzzle Workflow

**Status:** DO ANALIZY

## Project idea

A workflow for solving word-search puzzles with AI while keeping a human in the verification loop.

The project explores how a visual puzzle can be converted into a structured process: detecting words, recording their coordinates, marking directions, identifying unused letters and verifying the final answer.

## What this case study will show

- how the problem was broken into repeatable steps
- how a coordinate system was introduced
- how visual annotations were standardized
- how errors were detected and corrected
- how human verification improved AI output
- how the workflow evolved through repeated tests

## Current state

The workflow has been tested on several puzzles.

Source materials include solved examples, visual annotations, a step-by-step solving procedure and examples of mistakes that led to improvements in the process.

## Next step

Reconstruct the development process from the existing materials and select anonymized examples for the public case study.
